pebbler: Multivariate Statistics in Geoscience Made Easy

'pebbler' is a graphical R/Shiny workflow to perform multivariate 
statistical analysis. It is optimized for geoscience applications, e.g., 
sediment grains morphometry, geochemistry, particle size distributions, etc.

'pebbler' supports: 
 - compositional data preprocessing, 
 - computation of PCA and LDA with supplementary variables, 
 - biplot and scree plot visualization,
 - interactive measurements of angles and distances on a biplot.

## Installation

You can install the development version of 'pebbler' from [GitHub repository](https://github.com/SzymMol/pebbler) with:

``` r
# install.packages("pak")
pak::pak("SzymMol/pebbler")
```

## Usage

You can run 'pebbler' app in the following way:

``` r
library(pebbler)
run_pebbler() # opens pebbler app
```
